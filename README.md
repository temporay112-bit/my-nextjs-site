# SLOTS SPORTSWEAR — Website Pre-Build Package

This package prepares the planning files recommended in the supplied video before starting AI/Vibe Coding.

## Core files
1. `01-project-requirements.md` — what to build, target buyers, pages, features and business goals.
2. `02-architecture.md` — Next.js full-stack architecture, app flow, folder/file structure and technical stack.
3. `03-ai-development-guidelines.md` — rules for AI-assisted development, libraries, error handling, security and boundaries.
4. `04-development-phases.md` — phased implementation plan so the project is built and tested in controlled stages.
5. `05-design-system.md` — SLOTS SPORTSWEAR visual system for web/UI.
6. `06-memory.md` — living project memory to update after every meaningful implementation step.

## Website-specific addition
7. `07-asset-content-checklist.md` — exact photography, product visuals, factory visuals, catalogue and content assets required before production.

## Brand basis
The package is based on the supplied SLOTS SPORTSWEAR Brand Identity Guidelines PDF, the supplied logo, the website direction in the supplied video, and the requirements in the current brief.

## Primary implementation direction
- Framework: Next.js
- Architecture: App Router + full-stack Next.js
- Backend: Next.js Route Handlers / Server Actions
- SEO: technical SEO + structured data + sitemap + robots + canonical metadata
- Analytics: GA4-ready
- Search Console: verification-ready
- Mobile-first and responsive
- B2B lead-generation focused
- Real factory/product photography prioritized over generic stock or fake AI imagery
