# 12. SEO Requirements

The website must be SEO-friendly from the beginning.

## Technical SEO
- clean URL structure
- server-rendered/indexable content
- unique metadata per page
- canonical URLs
- XML sitemap
- robots.txt
- semantic HTML
- correct heading hierarchy
- Open Graph metadata
- Twitter/X metadata
- image alt text
- optimized images
- Core Web Vitals awareness
- 404 and error handling
- no accidental noindex on production pages

## Structured Data
Where relevant:
- Organization
- WebSite
- BreadcrumbList
- Product
- FAQPage

Only publish schema that accurately represents visible page content.

## Search Console readiness
Provide:
- verification-ready setup
- sitemap URL
- production-domain checklist

## Google Analytics readiness
Use GA4 with:
- page views
- quote CTA clicks
- catalogue clicks
- form submissions
- upload attempts
- contact/WhatsApp clicks

Track events without collecting unnecessary personal data.

---

# 13. Performance Requirements

- responsive image optimization
- lazy-load below-the-fold media
- minimal client-side JavaScript
- server components by default
- client components only where interaction requires them
- avoid heavy animation libraries when CSS/Framer Motion is sufficient
- avoid autoplay video unless it is essential and optimized
- fast mobile experience
- compressed modern image formats where practical

---

# 14. Trust & Brand Requirements

The website should feel:
- premium
- technical
- athletic
- precise
- professional
- international
- B2B
- manufacturing-led

Avoid:
- generic SaaS design
- flashy gradients unrelated to the brand
- excessive glassmorphism
- decorative fonts
- stock-photo-heavy pages
- fake factory scenes
- unverified claims
- crowded layouts

---

# 15. Definition of Done

The website is ready for production when:

- all core pages are complete
- all primary CTA paths work
- quote form works
- tech-pack upload works securely
- catalogue download works
- analytics events are verified
- Search Console is verification-ready
- sitemap/robots are valid
- mobile and desktop layouts are tested
- forms have error/success states
- production content is approved
- no placeholder images or copy remain
