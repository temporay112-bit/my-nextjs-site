# 3. Color Usage

Target ratio:
- 85–90% black / white / neutrals
- 10–15% electric lime maximum

Rules:
- black and white remain dominant
- lime is an accent, not a background system
- do not introduce random colors
- use strong contrast for B2B readability

Good uses for lime:
- CTA emphasis
- active navigation state
- small labels
- performance indicators
- separators
- small graphic accents
- interactive highlights

---

# 5. Suggested Type Scale

Desktop starting point:

- H1: 64px
- H2: 48px
- H3: 32px
- H4: 24px
- H5: 18px
- Body Large: 18px
- Body: 16px
- Body Small: 14px
- Caption / technical label: 12px

Use responsive clamp values in production instead of hard-coding one size for all screens.

---

# 6. UI Tone

Use:
- strong hierarchy
- clean spacing
- compact technical cards
- high-contrast sections
- thin dividers
- restrained rounded corners
- controlled shadows
- editorial imagery

Avoid:
- excessive pill UI
- huge border radii everywhere
- cartoonish icons
- soft pastel UI
- decorative gradients
- over-rounded SaaS cards

# 8. Icon Style

Iconography should be:
- minimal
- technical
- line-based
- consistent stroke weight
- monochrome by default

Useful capability icons:
- OEM manufacturing
- custom design
- quality control
- global shipping
- low MOQ
- factory
- fabric
- production
- packaging

Do not mix multiple icon styles.

# 12. Responsive Rules

Desktop:
- cinematic hero
- multi-column product grids
- broad whitespace

Tablet:
- condensed grid
- preserved hierarchy
- simplified navigation

Mobile:
- stacked sections
- large tap targets
- short text blocks
- swipe-friendly hero
- compact trust badges
- single-column forms

Never preserve desktop layouts by simply shrinking everything.

---

# 13. Accessibility

Minimum contrast target:
- normal text: 4.5:1
- large text: 3:1

Preferred:
- stronger contrast wherever practical
- never use lime text on white for critical information
- always provide visible focus

# V2 ADDITION — CERTIFICATES / SHIPPING / PAYMENT

AI coding must never invent certificate names, tax/compliance status, shipping methods, payment terms, lead times, bank details or company statistics. Keep placeholders until verified business data is supplied.

Certificates: use only approved documents and avoid public exposure of sensitive information.
Shipping: use a configurable data source; no fixed prices or delivery times unless verified.
Payment: use a configurable data source; no bank/account details or percentages unless explicitly approved.
Manufacturing: the complete 10-step process must be represented consistently across homepage and manufacturing page.
Why Choose: use evidence-based value propositions only.
